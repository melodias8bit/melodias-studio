One vibe in. A song, a still, a video out.

melodias-studio is the release pipeline for 8-bit music channels. Drop in a reference URL and a vibe; it writes the prompt, draws the cover art, composes an original instrumental chiptune, cuts the 1080p video plus a 9:16 vertical short with paste-ready captions, and hands you the YouTube copy. Eleven stages, one command, no editing timeline.

01

One command, one finished folder

Watch the eleven stages stream by in the TUI, or fire one headless command from CI. Either way the still, the track, the 1080p video and the YouTube copy land in one folder, picked by the judge or overridden by you.

Run it your way

No arguments opens the TUI; the two arguments run the same pipeline headless and take the judge suggestion. Config starts from config.example.toml at $XDG_CONFIG_HOME/melodias-studio/config.toml.

Eleven stages, one take

Everything lands in the folder

Still

The vibe becomes an English prompt with the pixel style pinned. The seed and steps travel with the image, so a patched retry replays exactly.

Track

An original instrumental, 210 seconds by default. The source is sampled for timbre only, then the master is faded and normalized to -15 LUFS.

Video

The chosen still with a slow zoom, the waveform, pixel particles and channel branding. Remotion by default; the ffmpeg path is explicit and fast. A 9:16 vertical cut with captions ships alongside for Shorts and TikTok.

YouTube copy

Title, two opening paragraphs and hashtags, written while the language model is already loaded. Rebuild it offline or with the cloud pass.

04

Questions, answered

The short version. The repository is the long version.

Do I need a GPU?

Generation happens on your own box behind three HTTP services. The defaults describe a single 24 GB card, reached over SSH, but local mode works too. Scoring, judging replays, exports and the dashboard need no GPU at all.

Is the music original?

Yes. Every track is an original instrumental; the reference audio only conditions timbre. The run stores prompts and seeds, so any piece can be replayed or audited later.

What if I have no judge key?

Nothing breaks. The TUI pauses so you can pick the candidates yourself, and headless runs take the best-scored default. A failed judge call is one log line, never an aborted run.

Can I rework a finished run?

Yes, per piece: regenerate the still, re-run the judge or the score, rebuild the YouTube copy, or re-render the video, all from the stored folder. Nothing requires paying for the full pipeline twice.

What do the scores mean?

60 percent deterministic rubric plus 40 percent editorial read. The gates are 80 total, 85 technical and 70 editorial. A run that misses after the retry loop is recorded as accepted by limit, with the reason stored in history.

Do you publish vertical Shorts?

make short DIR=output/<slug> cuts a 9:16 vertical from the loudest window with ffmpeg only, no LLM, and writes short.txt with paste-ready English captions for TikTok and YouTube Shorts. The same file posts natively to both.

Where does my data live?

On your machine. Runs stay in output/, history in a local SQLite file, config in your home directory. The only network calls are the ones you configure: your GPU host and, optionally, the judge provider.
